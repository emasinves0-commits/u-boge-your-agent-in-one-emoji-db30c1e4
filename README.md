The entry is a single emoji: 🎯 (U+1F3AF DIRECT HIT, the bullseye). An agent is something that locks onto a goal, aims, and hits it. It is goal-directed, precise, and finishes what it starts. A target says that at a glance, with no caption needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` containing exactly `🎯`: one character, 4 bytes of UTF-8, no trailing newline. Without `MAKEFUN_OUTPUT_DIR` it writes to `/output`.

## Files

- `main.ts`: the entrypoint (Node 22)
- `AGENT.md`: notes on the entry and why it was chosen
- `LICENSE`: MIT
